# v7.3 手機頂部固定＋回到頂部 — 規格（定稿）

## 0. 需求（使用者 2026-10-01 iPhone 實測 v7.2 後）
1. 捲動時頂部那列（頁面標題＋右上角「名字・登出」）一直留在畫面最上方。
2. 一鍵回到頂部按鈕：捲一段距離才出現，點了平滑捲回頂部；不擋底部分頁列與卡片按鈕。

## 1. 範圍
- **只套手機版**（v7.2 的媒體條件 `(max-width:600px), (max-height:500px)`）。電腦／iPad 不變（使用者：「網站的就維持網站」）。
- 頁面：潛在客戶（首頁清單）、客戶名單。專案詳細頁不在本版範圍（討論題）。
- 改 `index.html`、`styles.css`、`app.js`、`tests/**`。

## 2. 頂部固定
- 只固定**一行**：頁面標題＋右上角帳號區（名字・登出）。用專用 class（例如 `.page-header`）指定首頁與名單頁頁首，**不可用通用 `header` 選擇器**（專案詳細頁 `.detail-header` 已 sticky，`styles.css:17`，本版不改）。
- 捲動容器是 `main`；頁首 `position:sticky; top: var(--offline-height, 0px)`（離線橫幅出現時貼齊橫幅下緣，橫幅可換行，高度沿用 `app.js` 量測值）；背景不透明、底線保留；`z-index` 用 5（低於側欄／更多選單 10、離線橫幅 20、toast 30）。
- 頁首加 `padding-top: env(safe-area-inset-top, 0px)`（不改 viewport）。
- 客戶名單「重新整理」**移出頁首**，在所有手機寬度都放在頁首下方、跟著內容捲走（保留文字與 ≥44px）。電腦版位置不變。
- 名單分類標籤不固定；專案詳細頁不改；橫拿不縮小頁首。
- 刪除原「錨點捲動」要求（程式沒有頁內錨點：分類標籤與步驟連結都是切換後 `scrollTop=0`）；不新增全域 `scroll-margin-top`，不得影響抽屜內捲動。

## 3. 回到頂部按鈕
- **只出現在手機版的潛在客戶與客戶名單兩頁。** 圓形 ≥44×44、圖示＋`aria-label`「回到頂部」；右下角、底部列上方，右邊距 16px；`z-index` 8。
- 顯示門檻：`main.scrollTop > 240` 顯示、`< 80` 隱藏（中間維持原狀，避免閃爍）。狀態在 `scroll`（rAF 節流，讀當下值）、切頁、`renderLeads()` 重畫、資料變短、尺寸改變、程式設定 `scrollTop=0` 後都要重算；不可依賴會被 `#leads-view` 重寫清掉的哨兵元素。
- 隱藏一律用 `hidden`（離開 Tab 順序）：toast 顯示期間、「更多」選單開著、對話框／抽屜開著、未登入／登出／權限失效時。
- 點擊：`main.scrollTo({top:0, behavior:'smooth'})`；`prefers-reduced-motion` 時直接跳。捲動結束（`scrollend` 或等效判斷）後，對目前可見頁的 `h1`（設 `tabindex="-1"`）`focus({preventScroll:true})`；中途切頁或開對話框則取消。
- 底部留白：**只在兩個清單頁**於現有 `--mobile-bottom-space` 之外再加按鈕高度＋間距，讓最後一張卡的操作列能捲到按鈕上方；專案詳細頁留白不變。更新 `tests/mobile-nav.spec.js` 中「三頁留白相同」的斷言為各頁實際遮擋驗證。

## 4. 驗收（Playwright 375×812、600×900、844×390；768×1024、1280×800 不變）
1. 兩個清單頁捲到中段與底端，頁首位置不變、名字與登出可實際點擊；離線時頁首上緣在橫幅下緣、「重試」可點。
2. 名單頁「重新整理」在頁首下方、可點、捲動後離開畫面；電腦版位置不變。
3. 回頂：未捲動不可見；`scrollTop>240` 可見；回到 <80 隱藏；點擊後以可重試斷言等待 `scrollTop===0` 與標題取得焦點；≥44px；reduced-motion 直接跳；捲動中切頁不殘留。
4. toast 出現時回頂隱藏；更多選單、抽屜、對話框開著時隱藏；登出／未登入時不存在於可見與 Tab 順序。
5. 最後一張卡的操作列完整高於回頂按鈕與底部列；整頁無橫向捲動。
6. 專案詳細頁原有 sticky 行為不變、無回頂按鈕；768／1280 清單頁首與無回頂按鈕不變。
7. 既有測試全過，連跑 2 次。
- iPhone 實測（使用者）：直拿、橫拿捲動時頁首固定、回頂按鈕好按、不擋卡片按鈕。

## 5. 兩方採納紀錄
- **一致**：重新整理移出固定列、分類不固定、詳細頁不改、toast 時隱藏回頂、橫拿不縮小、頁首 z-index 低於選單、錨點前提刪除、標題 tabindex＋scrollend 後聚焦、用 hidden 隱藏。
- **Grok 採納**：`top: var(--offline-height)`、門檻 240／80 遲滯、不用通用 header 選擇器、生命週期與哨兵問題。
- **Codex 採納**：重算時機、捲動中切頁取消、可重試斷言、只在清單頁加留白並改寫既有斷言。

## 6. 預估
Codex 實作＋測試約 1.5–2.5 小時；iPhone 實測 10 分鐘。
