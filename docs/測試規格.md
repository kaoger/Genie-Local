# 自動化測試規格（Playwright）

> 實作者：Codex。複查：Claude。目的：把 `docs/v4-規格.md` 第 8 節與第 9.4 節的驗收（1～20）變成可一鍵重跑的測試。

## 環境與限制
- 使用 `@playwright/test`（本機已全域安裝 1.63，瀏覽器 chromium-1243 已下載）。在專案加 `package.json`，只放 devDependency `@playwright/test`（版本 `1.63.0`）與 script `"test": "playwright test"`。**產品本身仍是免建置、無執行期相依套件**。
- `playwright.config.js`：`testDir: 'tests'`、只用 chromium、headless、`webServer` 執行 `python -m http.server 4173 --bind 127.0.0.1`，`url: http://127.0.0.1:4173`，`reuseExistingServer: true`。
- **禁止**：自己用 `child_process` 啟動瀏覽器、`--remote-debugging-port`、CDP／Puppeteer、在 TEMP 放腳本（見 AGENTS.md，會觸發 Apex One）。只能用 `npx playwright test`。
- 每個測試開始前清空 localStorage，互不相依。
