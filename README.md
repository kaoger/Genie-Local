# 潛在客戶本機工作台

直接雙擊 `index.html`，使用 Chrome 或 Edge 開啟即可。無需安裝套件。

依照參考網站的潛在客戶清單重現側欄、表格、完成狀態與分頁。聯絡人與聯絡方式改用示範資料。

## v3 新增：專案內頁

- 點專案名稱進入專案內頁（網址 `#/p/專案ID/步驟`，瀏覽器上一頁可返回）。
- **步驟列**：需求總覽 → 策略企劃 → 視覺發想 → 3D 建模 → 業務估價 → 提案簡報。
  - 標題與步驟分成兩行，名稱再長也不會擠壞步驟列；捲動時固定在畫面上方。
  - 每一步顯示狀態：✓ 已完成、🔒 還不能開始（並寫出原因）、! 需要更新。
- **需求總覽**：依區塊分成卡片（聯絡資訊、房屋概況、空間需求、備註）。
  - 上方顯示「AI 必填」完成度與缺少的欄位，點一下就能補。
  - 點任何欄位，或按「編輯全部資料」，會從右側打開**完整表單**，全部改完只要按一次儲存。
- **完整表單**：
  - 電話、Email、日期、坪數（數字＋坪）、格局（房／廳／衛）都有對應的輸入方式。
  - 風格、空間成員、裝修類型等欄位改成可點選的標籤；單選標籤再點一次可以取消。
  - 上方可以跳到指定區塊；Ctrl＋S 儲存；還沒儲存就關閉，會先提醒。
  - 需求類型改成非居家類型時，表單會自動換成「專案資訊」欄位。
- 策略企劃生成後，如果又修改了 AI 必填欄位，會標示「需要更新」，並提供「重新生成」按鈕（示範版不連接 AI）。
- 新增專案後會直接進入該專案，並提示繼續填寫需求。

## 已實作（v2）

- 新增、複製專案。
- 刪除確認及 10 秒內復原。
- 單筆或多筆完成狀態切換。
- 每頁 8 筆、分頁與選取。
- 本機知識庫筆記、顯示名稱及 JSON 匯出。
- 本機儲存、鍵盤操作及手機橫向捲動表格。

## 調整欄位

表單欄位都寫在 `app.js` 最上方的「表單欄位定義」。要新增或修改欄位，只要改那裡，專案內頁與表單會一起更新：

- `top:true`：存在專案本身（清單會顯示）。
- `ai:true`：生成策略企劃的必填欄位。
- `type`：text / email / tel / date / month / number / select / textarea / chips / layout。

## 資料與範圍

這是獨立前端示範，不連接原網站帳號、後端或 AI。資料存在目前瀏覽器的 localStorage，清除瀏覽器資料即會移除。舊版（v2）資料會自動沿用，並補上空白的需求欄位。視覺發想之後的步驟只有狀態與說明，內容尚未製作。
